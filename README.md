# 美股数据看板

本地运行：

```bash
npm start
```

默认打开 `http://127.0.0.1:4173`。如果端口被占用，服务会自动尝试后续端口，并在终端输出实际 URL。

## Render 部署

仓库包含 `render.yaml`，可以在 Render 上用 Blueprint 部署：

1. 将代码推送到 GitHub 仓库。
2. 在 Render 选择 New > Blueprint，并连接这个仓库。
3. Render 会读取 `render.yaml`，创建 Node Web Service。
4. 部署完成后访问 Render 分配的公网域名。

部署配置：

- Build Command: `npm install`
- Start Command: `npm start`
- Health Check Path: `/api/health`
- Host: `0.0.0.0`

当前版本不使用 Render persistent disk。所有行情和估值数据都在请求时实时获取；5 只场内 ETF 的溢价累计总和、样本数和平均值保存在浏览器本地存储中，因此页面刷新、服务重启或重新部署后仍会继续累计。该历史按浏览器设备独立保存，清理站点数据会重新开始记录。

## 数据源

- 纳指100期货、标普500期货：新浪财经全球期货 `hq.sinajs.cn`
- 境内 ETF 价格与 IOPV：新浪财经 ETF/IOPV `hq.sinajs.cn`
- 境内 ETF 基金规模：东方财富基金移动接口 `fundmobapi.eastmoney.com`
- VIX：Cboe delayed quotes `cdn.cboe.com/api/global/delayed_quotes/quotes/_VIX.json`
- 纳指100回撤：腾讯证券美股日线 `web.ifzq.gtimg.cn`
- 场外基金限购：东方财富基金移动接口 `fundmobapi.eastmoney.com`
- 纳指 PE 估算：Alpha Vantage `ETF_PROFILE` 的 QQQ 成分权重 + 东方财富美股动态 PE `f9`

## PE/PEG

看板会自动估算当前纳指 PE：用 QQQ 成分权重抓取成分股，再用东方财富美股动态 PE 做盈利收益率调和估算。这个值适合做看板参考，不等同于 Nasdaq 官方指数估值。

免费公开源暂未验证到稳定的纳指100 PEG 和 PE/PEG 历史分位接口。当前版本暂时不展示历史分位，也不在本地或云端自动累积历史估值样本。

可选接入方式：

1. 维护 `data/valuation.json`，填入 `current.peg`；如需要覆盖估算 PE，也可以填 `current.pe`。
2. 设置 `ALPHAVANTAGE_API_KEY` 后启动服务，服务端会尝试读取 QQQ `OVERVIEW` 的 PE/PEG。

```json
{
  "current": {
    "pe": null,
    "peg": 1.8
  }
}
```

## 标普500月内择时实验

在实时监控卡片下方，新增25日至次月5日实验。`/api/sp-timing`沿用腾讯日线接口，缓存一分钟，并保守排除美东当日日线。窗口前收盘为涨跌基准；最大收盘回撤含基准与运行最高收盘。首次达到阈值后，下个窗口内交易日收盘执行，避免使用当天收盘信号同时成交。未触发时按5日兜底；休市顺延只限窗口内，无可用交易日则保留空值。

固定25日、1日、5日对照使用相同指数收盘口径；份额差为“5日价格/策略买入价格-1”，同金额且不含费用、汇率。默认2%为可调整实验值，不是历史优化结果。每期规则保存后冻结，窗口开始后登记会标为回顾。规则及执行日志保存在独立的`stockboard.spTiming.v1`浏览器存储中，可导出JSON；不影响原ETF历史键。历史验证目前明确为占位，不输出虚构回测。运行`npm test`覆盖跨年、休市、下一交易日执行及缺失数据情形。

### 自动归档与累计分析

已实现浏览器内自动归档：仅对保存过规则的月份，在日线出现窗口结束日之后的记录、且有临近基准和窗口行情时，保存基准、窗口每日收盘、首个窗口后日线、冻结规则和结果快照。归档按月份幂等保存，刷新不会覆盖；之后行情滚出接口范围也可查看归档。需打开看板才能执行，关闭时不运行后台任务。缺少行情、未结束或超过接口范围的窗口保持待归档，不虚构结果。

累计统计以固定5日为基准，按阈值及事前/回顾分组，展示归档数、可比数、触发率、胜率、平均份额差和最差一期。零差为平局，不计胜。缺少执行价或5日对照价的归档不计可比数，但保留在总样本及触发率中。事前登记按美东日期严格早于25日判定。不同阈值不混算。

新执行日志保存结构化日期、买入价、备注及可选同一标的5日净值。可事后补充对照净值，逐笔显示同金额份额差；多笔不合并为收益，不与指数点位混算。旧文字日志继续保留，不猜测其价格。导出包含所有规则、归档和日志；导入只合并新增规则和日志，已有规则/归档不覆盖，归档从备份日线重算校验。所有数据仍保存在当前浏览器，清理站点数据会丢失，建议定期备份。
